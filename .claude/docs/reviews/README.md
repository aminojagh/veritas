# Step Reviews

One file per Step: `step-NNN-<slug>.md`, matching its plan. A `## Sub-step N.M`
section is appended each time a Sub-step closes — that section is what Amino
reads before committing.

A Step Review is a handoff, not a changelog. It answers: what changed, what
proves it works, what I chose to leave undone, and what you should look at
sceptically. See the `closing-a-substep` skill.

Reviews report failures plainly. A Sub-step that did not fully work, reported
honestly, is worth more than a green one that lies.
